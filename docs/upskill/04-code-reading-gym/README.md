# Code Reading Gym

This section makes the learner work: annotate, trace, contrast bad fake code with real patterns, and review fake PRs. Use [01-annotation-drills.md](01-annotation-drills.md), [02-trace-tables.md](02-trace-tables.md), [03-fake-code-contrasts.md](03-fake-code-contrasts.md), and [04-review-katas.md](04-review-katas.md).

Self-grade every exercise:

- Basic: you can name files and explain the happy path.
- Solid: you identify inputs, outputs, dependencies, invariants, side effects, and failure modes.
- Strong: you propose a test, a rollback path, and a narrower alternative.
