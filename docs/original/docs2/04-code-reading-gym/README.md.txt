# 04 — Code Reading Gym

Reading code is a trainable skill, distinct from writing it. This module is a gym: drills that force
you to read *actively* — predict, annotate, trace, and critique — instead of skimming.

| File | The drill |
| --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate a real method's inputs, outputs, deps, invariants, side effects, failure modes. |
| [02-trace-tables.md](02-trace-tables.md) | Step through execution by hand, tracking value shapes and risk. |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad-vs-better pairs tied to real patterns here. |
| [04-review-katas.md](04-review-katas.md) | Review fake PRs against this codebase; find the planted issues. |

**How to use the gym:** don't read the answers first. For each drill, do your own pass on paper, *then*
check against the provided annotation/trace. The gap between your pass and the model answer is the
lesson. Rotate files so you're not always reading the engine.
